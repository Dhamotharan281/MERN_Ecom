10. Responsive Design

Tailwind is mobile-first.

Prefix	Screen
sm:	small screens
md:	tablets
lg:	laptops
xl:	large screens

| Class     | Why                             |
| --------- | ------------------------------- |
| `py-16`   | Vertical spacing                |
| `px-4`    | Side padding on small screens   |
| `lg:px-0` | Remove extra padding on desktop |
| `m-4`     | Outer margin from page edges    |

| Class               | Job                               |
| ------------------- | --------------------------------- |
| `container mx-auto` | Centered responsive width         |
| `flex`              | Enables flexbox layout            |
| `flex-col-reverse`  | Mobile → image on top, text below |
| `lg:flex-row`       | Desktop → text left, image right  |
| `items-center`      | Vertical alignment                |
| `bg-green-50`       | Soft premium background           |
| `rounded-3xl`       | Modern curved card look           |
| `border-black/10`   | Subtle border                     |
| `overflow-hidden`   | Prevent image from leaking out    |
